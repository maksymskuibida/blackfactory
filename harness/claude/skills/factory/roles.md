# Roles

Besides builder, reviewer and verifier there are more roles: `uiux-verifier`, `security-expert`, `security-auditor`, `lawyer`, `legal-auditor`, `design-reviewer`, `designer` and `uiux-designer`, and the three that the engine lists when it names them: `fix-designer` (designs the fix of a checkpoint), `knowledge-writer` (writes the note of code knowledge) and `rule-proposer` (proposes rules). `bf roles list` names them and their limits; each has a role file in `.claude/agents/`, and each role file names the model for its kind of work.

The designer drafts a design stage or an amendment on the model and effort the policy names for it (`bf policy`); the design reviewer judges the records of a gate or an amendment; the UI/UX designer drafts screens and journeys as a stage designer. Put every record with `--token <token> --model <the model the agent runs on>`. An advisor, for a question that needs judgment, has no directive and no token: read its tier, effort and model in `bf policy` before you start one, and relay its answer word for word with its model.

For each role, `bf roles token <unit|design> <role>` issues its token and `bf brief <unit|design> --role <role>` writes its brief. A design-stage role works on the subject `design`, before any plan exists, and has no working copy: it works in the main checkout. Start it like any other worker, on the model its directive names, with the brief path, its working copy (for a design-stage role, the main checkout), the limits and its token.

**Tokens.** You never use a worker's token yourself: you only pass each token to the agent of that role. Never settle a check, attach an outcome, file a review or file a report with a token, in any role's name. The one exception is the report you file for a worker under a budget cap: relay its own result and findings unchanged. The engine cannot enforce this, since a token tells roles apart and does not keep you out, so this is the one rule in these instructions that the engine does not enforce, an exception to the rule that the instructions state nothing the engine does not enforce, and it rests on you alone.
